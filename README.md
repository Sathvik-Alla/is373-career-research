# IS373 Career Research

Employer evidence and portfolio decisions for Sathvik Alla's Review 1 Plan.

The VitePress site organizes the research into employer postings, career directions, the portfolio plan, and checks. Each page is generated from the relevant sections of `research.md`, so updates to the research only need to be made once.

Run `npm ci` and `npm run dev` to preview locally. Run `npm run build` to check the production build. The included workflow publishes from `main` after GitHub Pages is configured to use GitHub Actions.

- [Employer postings and eligibility](research.md#employer-postings)
- [Role comparison and provisional decision](research.md#career-directions)
- [Public page outline and layout choice](research.md#layout-options)
- [Actual checks and pending peer review](research.md#portfolio-actual-checks)
